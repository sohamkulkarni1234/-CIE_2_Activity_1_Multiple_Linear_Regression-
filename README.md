CIE_2_Activity_1_Multiple_Linear_Regression

Dataset Source
Dataset Name: California Housing Dataset

Source: Scikit-learn / StatLib

Dataset Link: https://lib.stat.cmu.edu/datasets/houses.zip

Documentation: https://scikit-learn.org/stable/datasets/real_world.html

Dataset Description: The California Housing Dataset contains information about houses in different California districts, based on the 1990 U.S. Census.

Input Features:

Median Income (MedInc)
House Age (HouseAge)
Average Rooms (AveRooms)
Average Bedrooms (AveBedrms)
Population
Average Occupancy (AveOccup)
Latitude
Longitude
Target Variable: MedHouseVal (Median House Value)

Objective: To predict median house values using Multiple Linear Regression.
